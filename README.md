# Slasher (@Dirfiks3)

[Telegram](https://t.me/slasher_dev) | [GitHub](https://github.com/Dirfiks3)

13 y.o. developer focused on Android internals, custom firmware, and system-level tweaking.

Most of my time goes into building AOSP / LineageOS-based firmware. I strip out system bloatware, harden kernel parameters, and tune performance to make devices run fast without background telemetry. Besides firmware, I develop privacy-focused mobile clients and Linux CLI/TUI tools.

## Active Projects

*   **Voidroid** — Hardened and heavily debloated custom ROM based on LineageOS 22.1 (Android 15) for Samsung Galaxy A51 (SM-A515F). Features kernel `sysctl` hardening, TCP BBR, anti-bootloop watchdog, and zero Google telemetry.
*   **VoidMAX** — Telemetry-free, privacy-hardened client for the MAX messenger built with React Native.
*   **DistroScope** — Interactive Linux distribution finder web app. ([Repo](https://github.com/Dirfiks3/DistroScope) | [Live](https://distroscope.pages.dev))
*   **lfs-gentoo-tui** — Terminal UI helper for building Linux From Scratch and Gentoo systems. ([Repo](https://github.com/Dirfiks3/lfs-gentoo-tui) | [Live](https://dirfiks3.github.io/lfs-gentoo-tui))
