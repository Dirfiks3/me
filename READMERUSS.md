Вырезаю системный мусор, настраиваю параметры ядра и оптимизирую производительность, чтобы устройства работали быстро и без фоновой телеметрии. помимо прошивок, разрабатываю клиенты для мобильных устройств с упором на приватность и консольные утилиты для Linux.

## Текущие проекты

*   **Voidroid** — Защищенная и сильно урезанная кастомная прошивка на базе LineageOS 22.1 (Android 15) для Samsung Galaxy A51 (SM-A515F). Включает харденинг ядра через `sysctl`, TCP BBR, сторожевой таймер от бутлупов и полное отсутствие телеметрии Google.
*   **VoidMAX** — Клиент мессенджера MAX без телеметрии и с усиленной защитой приватности, написанный на React Native.
*   **DistroScope** — Интерактивное веб-приложение для подбора дистрибутива Linux. ([Repo](https://github.com/Dirfiks3/DistroScope) | [Live](https://distroscope.pages.dev))
*   **lfs-gentoo-tui** — Консольная утилита (TUI) для сборки систем Linux From Scratch и Gentoo. ([Repo](https://github.com/Dirfiks3/lfs-gentoo-tui) | [Live](https://dirfiks3.github.io/lfs-gentoo-tui))
